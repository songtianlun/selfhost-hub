Tale combines project tasks, shared context and AI agent work in a team workspace. Teams can prepare task briefs and attachments, assign an agent, explicitly start work, and review the reports and files it returns.

## Main features

- Project task boards with task briefs, attachments and shared project context.
- Agent work in persistent project workspaces, with progress and results available for review.
- Shared knowledge and reusable automations alongside project work.
- An authenticated HTTP MCP endpoint for knowledge and automation tools on the team's own deployment.

## Self-hosting

Follow the [official installation quickstart](https://docs.tale.dev/self-hosted/install/quickstart) for the supported Docker setup and configuration. Community software is free under the MIT license; infrastructure and model usage are separate costs. Optional Enterprise operation and support services are available.

Assigning an agent does not start it automatically: work is started explicitly, and returned deliverables should be reviewed.
