UnfoldCMS 是一个基于 Laravel 12 和 React 19 构建的自托管内容管理系统，提供现代化的管理界面和强大的 API 功能。

## 主要功能

- **REST API v1**：提供 42 个端点，支持无头 CMS 模式
- **HMAC Webhooks**：安全的出站 Webhook 支持
- **现代化界面**：基于 shadcn/ui 和 Tailwind v4 构建
- **多模板支持**：灵活的主题和模板系统
- **博客与页面管理**：完整的内容创建和发布工作流
- **SEO 工具**：内置 SEO 管理功能
- **权限管理**：细粒度的角色和权限控制

## 部署要求

- PHP 8.2 或更高版本
- MySQL 8.0 或更高版本
- Node.js 18.x（用于前端构建）
- 推荐配置：2核 CPU，2GB 内存
- 支持 Docker 部署
